刻蚀选择比计算器 Etch Selectivity Calculator

S(film : mask) = ER(film) / ER(mask) · 与技能 etch-selectivity-calc 同一套算法 · 纯本地计算，不上传任何数据

由两个刻蚀速率求选择比 S = ER(film) / ER(mask)

适用：已分别做空白片速率实验。两个速率使用相同单位，选择比与单位无关。

由厚度损失求选择比 S = Δfilm / Δmask（同一步刻蚀）

最常用的实测法：椭偏/探针分别测同一步刻蚀前后目标膜与光刻胶厚度，损失相除即 S。两组数据必须来自同一时刻窗口。

掩膜余量校核 消耗 = film × (1 + 过刻蚀) / S

剩余掩膜不足初始厚度 10% 时给出黄色预警——片内均匀性与端点检测误差足以吃穿这点余量。

反推所需最小选择比 Smin = film × (1 + 过刻蚀) / (预算 × mask)

得到 Smin 后，到"参考数据"页确认该量级属于"调工艺可及"还是"必须换掩膜方案（硬掩膜/OPL）"。

经验法则

  • PR 掩膜通用下限：S(film:PR) ≥ 5 才考虑 20% 级过刻蚀；2~5 需压缩过刻蚀或上硬掩膜；< 2 不可行。
  • 提高对 PR 选择比：降 O₂ 比例、增聚合（C₄F₈/CH₂F₂/CHF₃）、降腔温、PR 硬烘烤/UV 固化、上 OPL 或硬掩膜。
  • 提高对下层选择比：降偏压功率（降离子能量）、加刻停层、换低能化学气（HBr 对氧化硅）。
  • 代价权衡：聚合型化学气选择性高但易残留、CD 漂移；SF₆ 系对 Si:SiO₂ 选择比高但各向同性、形貌不可控。
